# GREEN-API Chat

## Запуск

```bash
npm i
npm run dev
```

Откройте http://localhost:5173.

## Подготовка инстанса

1. Зарегистрируйтесь в [личном кабинете](https://console.green-api.com) и создайте инстанс **Telegram**.
2. Авторизуйте инстанс своим аккаунтом Telegram — статус должен стать `authorized`.
3. В настройках инстанса включите получение уведомлений о входящих сообщениях и о статусах исходящих сообщений.
4. Скопируйте `idInstance` и `apiTokenInstance`.

## Проверка

1. Введите `idInstance` и `apiTokenInstance` на странице входа.
2. Нажмите ✎ и введите номер получателя, например `+7 999 123-45-67`.
3. Отправьте сообщение — оно придёт получателю в Telegram.
4. Ответьте из Telegram — ответ появится в чате.
